# Security Policy

## Scope

This repository is a defensive demonstration project. Do not submit real credentials, access tokens, session cookies, private keys, or sensitive production telemetry in issues or pull requests.

## Reporting

If you find a security problem in a deployed copy, report it privately to that deployment's owner. Do not include exploit secrets or private user data in a public issue.

## Model-artifact warning

Joblib/Pickle-style model files must be treated as executable trusted artifacts. Never load a model file from an untrusted source.
